# Vehicle Automation Test

Vehicle Automation Test is a configurable platform for automated testing of
vehicle, agricultural, industrial, and embedded control products.

The platform is intended to support Software-in-the-Loop (SIL),
Hardware-in-the-Loop (HIL), physical controller testing, communication
simulation, diagnostic testing, fault injection, test execution, and
traceable result reporting.

Customers will be able to install the application, import a product package,
configure supported hardware, and execute tests without modifying the
platform source code.

## Project status

The project is currently in the Minimum Viable Product (MVP) development
phase.

## Repository rules

- Project-controlled file and folder names use lowercase words separated by
  underscores.
- External customer and vendor filenames are preserved.
- Every project-controlled folder contains a short `README.md`.
- Acronyms are written in full the first time they appear in each document.
- Customer data remains separate from platform source code.
- Dependencies must be reviewed before they are added.
