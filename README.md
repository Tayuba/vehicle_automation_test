# Vehicle Automation Test

Vehicle Automation Test is a configurable platform for automated testing of
vehicle, agricultural, industrial, and embedded control products.

The platform supports Software-in-the-Loop (SIL), Hardware-in-the-Loop (HIL),
physical controller testing, communication simulation, diagnostic testing,
fault simulation, automated test execution, and traceable result reporting.

Customers can install the application, import a product package, configure the
available test environment, and execute product-specific tests without
modifying the platform source code.

## Core capabilities

- Customer product-package import
- Vehicle and industrial communication support
- Electronic Control Unit (ECU) simulation and emulation
- Plant and fault simulation
- Automated test-sequence execution
- Diagnostic Trouble Code (DTC) handling
- Live operator and engineering interfaces
- Structured test results and evidence
- Software and physical HIL execution
