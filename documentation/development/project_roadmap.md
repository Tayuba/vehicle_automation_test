# Project Roadmap

The roadmap describes the planned development sequence for Vehicle Automation
Test.

## Foundation

- Repository structure
- Build system
- Dependency management
- Versioning
- Product documentation
- Automated testing infrastructure

## Product data

- Vehicle Test Package
- Package manifest
- Schema validation
- Product model
- Product variants
- Customer data import

## Communication

- Virtual Controller Area Network (CAN)
- CAN frame model
- CAN trace recording
- Society of Automotive Engineers J1939 (SAE J1939)
- CANopen
- Unified Diagnostic Services (UDS)
- ISOBUS
- Additional vehicle and industrial protocols

## Simulation

- Simulation runtime
- Virtual Electronic Control Units (ECUs)
- Plant models
- Fault models
- Trace replay
- Functional Mock-up Unit (FMU) support

## Test execution

- Open Test Automation Platform (OpenTAP) integration
- Test-plan generation
- Execution state reporting
- Timeout handling
- Cleanup handling
- Result collection

## Applications

- Operator station
- Engineering console
- Product package import
- Test execution
- Communication monitoring
- Diagnostic monitoring
- Simulation control
- Result viewing

## Physical HIL

- Hardware abstraction
- CAN hardware adapters
- Digital input and output
- Analog input and output
- Power control
- Load control
- Fault injection
- Safety interlocks

## Reporting and traceability

- Structured results
- Hypertext Markup Language (HTML) reports
- Portable Document Format (PDF) reports
- Comma-Separated Values (CSV) exports
- Database storage
- Requirement traceability
- Calibration records
- Audit evidence

## Deployment

- Microsoft Windows installer
- Portable Windows package
- Linux deployment
- Command-line execution
- Offline deployment
- Multi-station deployment
